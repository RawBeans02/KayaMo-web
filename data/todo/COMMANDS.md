# Signature planner commands

Home owns these. Desktop `/todos` stays a review checklist until the timetable
ships. No sixth PWA tab.

| Command | User intent | Mus must |
|---|---|---|
| Plan my day | Build a realistic day | Events first; leave whitespace; ask to save |
| Plan tomorrow | Same for next logical date | Do not steal tonight’s unfinished work silently |
| Replan remaining | Day slipped | From *now*; keep history |
| Rescue | Day collapsed | Must-do vs move vs shrink |
| Minimum day | Low capacity | Meaningful minimums |
| What can I do now | Short window | Rank by duration, location, energy |
| Fill free time | Frame already locked | Only AUTO/FLEXIBLE in gaps |
| Optimize | Manual schedule exists | List 2–4 improvements; do not rewrite until accept |
| Brain dump | Mixed speech | Inbox/task proposals; ask only where time is hard |
| Ask about this | Inspector | Scoped to the selected block |

Negotiate when work does not fit. Never invent a miracle calendar.
